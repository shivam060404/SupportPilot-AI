# Security Incidents

If you suspect a security incident, such as a phishing email, malware, or unauthorized access:

1. **Do not click any links or open attachments.**
2. If it is an email, use the "Report Phishing" button in Outlook/Gmail.
3. If you believe your machine is compromised, disconnect it from the network immediately (turn off Wi-Fi or unplug the Ethernet cable).
4. Do NOT turn off the computer, as this can destroy forensic evidence.
5. Escalate to the Security Operations Center (SOC) immediately.

Security incidents take top priority. Do not hesitate to report suspicious activity.
