# Application Access

If you cannot access a specific company application (e.g., Salesforce, Workday, Jira):

1. **Clear Browser Cache**: If using a web application, clear your browser cookies and cache, or try an Incognito/Private window.
2. **Check Permissions**: Ensure you have been granted access to the application by your manager.
3. **SSO Issues**: If you receive a Single Sign-On (SSO) error, try logging out of Okta/Azure AD and logging back in.
4. **Desktop Apps**: For installed applications, check the Software Center or Self Service app for any pending updates.

If the application is displaying an internal server error or 503, it may be experiencing an outage. Please check the service status.
