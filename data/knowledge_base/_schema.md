# Knowledge Base Document Schema

All KB documents must follow this frontmatter schema:

```yaml
---
title: Human-readable document title
category: VPN | Password | WiFi | Application | Security | Email | Printer | Onboarding
source: Team or department that owns this document
last_updated: YYYY-MM-DD
access_level: ALL_EMPLOYEES | IT_STAFF | MANAGERS | EXECUTIVES
---
```

## Content Guidelines
- Use clear headings (##, ###)
- Number troubleshooting steps
- Include expected outcomes for each step
- End with escalation path
- Avoid jargon without explanation
